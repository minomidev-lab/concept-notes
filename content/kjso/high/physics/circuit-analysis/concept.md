## 직렬·병렬 합성 저항

여러 저항이 한 줄로 연결된 **직렬 연결**에서는 각 저항에 같은 전류가 흐르고, 합성 저항은 각 저항의 합이다.

$$R_{\text{직렬}} = R_1 + R_2 + \cdots + R_n$$

여러 저항의 양 끝이 공통으로 묶인 **병렬 연결**에서는 각 저항에 같은 전압이 걸리고, 합성 저항의 역수는 각 저항의 역수의 합이다.

$$\frac{1}{R_{\text{병렬}}} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n}$$

저항이 두 개뿐인 병렬 연결은 $R_{\text{병렬}} = \dfrac{R_1 R_2}{R_1+R_2}$로 계산하면 편리하다. 병렬 합성 저항은 항상 그중 가장 작은 저항보다도 작다는 점에 유의한다.

## 전력

전기 회로가 단위 시간당 소비하는 에너지인 **전력** $P$는 전압 $V$, 전류 $I$, 저항 $R$ 사이에서 다음과 같이 표현된다.

$$P = VI = I^2R = \frac{V^2}{R}$$

같은 전류가 흐를 때는 저항이 클수록, 같은 전압이 걸릴 때는 저항이 작을수록 소비 전력이 크다는 점이 직렬·병렬 회로의 전력 배분을 판단하는 기준이 된다.

## 복합 회로의 단계적 단순화

직렬과 병렬이 섞인 **복합 회로**는 한 번에 풀려 하지 말고, 가장 안쪽의 단순한 직렬 또는 병렬 부분부터 하나의 등가 저항으로 치환해 나가며 회로를 단순화하는 것이 효율적이다. 마지막에 남은 전체 합성 저항에 옴의 법칙 $V=IR$을 적용하면 전체 전류를 구할 수 있다.

**예제.** 기전력 $12\ \text{V}$인 전원에 저항 $R_1=2\ \Omega$이 직렬로 연결되고, 그 뒤에 $R_2=6\ \Omega$과 $R_3=3\ \Omega$이 병렬로 연결되어 있다. 전체 전류를 구하여라.

**풀이.** $R_2$와 $R_3$의 병렬 합성 저항은

$$R_{23} = \frac{R_2 R_3}{R_2+R_3} = \frac{6\times3}{6+3} = 2\ \Omega$$

이를 $R_1$과 직렬로 더하면 전체 합성 저항은 $R = R_1 + R_{23} = 2+2 = 4\ \Omega$이다. 옴의 법칙에 의해 전체 전류는

$$I = \frac{V}{R} = \frac{12}{4} = 3\ \text{A}$$

이다.

에너지 보존의 관점에서 전력을 계산하는 이 방법은, 중등부에서 다룬 열량 계산과 함께 전기 에너지가 열로 전환되는 현상을 정량적으로 이해하는 데 이어진다.
